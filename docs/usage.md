# QuickBox 使用指南

把常用开发工具、Linux 命令手册和个人资料放在一个工作台里，用键盘快速找到、处理和保存。

[返回项目首页](../README.md) · [下载安装包](https://github.com/CrescentR/Quick-Box/releases) · [开发指南](development.md) · [发布说明](release.md)

## 1. 安装与第一次使用

### 选择安装包

到 [GitHub Releases](https://github.com/CrescentR/Quick-Box/releases) 展开对应版本的 **Assets**，选择当前系统的安装包。

| 系统 | 文件 | 使用方式 |
| --- | --- | --- |
| Windows x64 | `QuickBox_*_windows_x64_setup.exe` | 日常使用推荐，按向导选择安装目录 |
| Windows x64 | `QuickBox_*_windows_x64.msi` | 适合需要 MSI 安装方式的场景，同样需要指定合适的安装目录 |
| Linux x64 | `QuickBox_*_linux_x64.AppImage` | 放在用户可写目录，赋予执行权限后运行 |
| Debian / Ubuntu x64 | `QuickBox_*_linux_x64.deb` | 系统安装包；当前数据路径跟随程序目录，需注意安装位置的写权限 |

日常使用优先选择正式发行版；带 **Pre-release** 标记、标签包含 `-build.` 的版本是自动构建的预览版。`Source code` 是源码压缩包，不是安装程序。需要核对下载完整性时，可对照同一发行版中的 `SHA256SUMS.txt`。

> **Windows 安装位置**：请选择非 C 盘且当前用户可写的目录，例如 `D:\Apps\QuickBox`。应用默认把数据放在安装目录下的 `data` 文件夹，安装目录本身也需要可写。程序会拒绝 C 盘数据路径，包括实际指向 C 盘的目录联接。

<a id="linux-notes"></a>

### Linux 安装说明

AppImage 以自身所在目录为安装目录，建议放在自己的可写文件夹中。deb 的系统安装位置通常不可写，当前存储方案在这种位置存在使用限制；安装包成功生成不表示已消除这项运行限制。

### 打开你的第一个工具

1. 启动 QuickBox，按默认全局快捷键 **`Alt+Space`** 呼出窗口；再次按下可隐藏窗口。
2. 在搜索框输入工具名称或用途，例如 `JSON`、`时间戳`、`Base64`、`端口`。
3. 按 `↑` / `↓` 选择结果，按 `Enter` 打开；也可以直接点击。
4. 在工具中输入内容，使用工具提供的处理、复制或导出按钮。
5. 选中高频工具后按 `Ctrl+D`，把它加入“常用置顶”。

应用有三个主要入口：**启动器**负责找工具，**插件管理**负责启停工具，**设置**负责外观、快捷键、数据位置和备份。

## 2. 用搜索和常用置顶组织工具

启动器支持工具名称、中英文关键词和模糊匹配；相关度与使用记录会影响结果排序。搜索后还可以用分类缩小范围，例如编码、文本、开发或系统相关工具，以界面当前分类为准。

“常用置顶”最多保存 **8 个工具**。可以拖动列表中的工具到置顶区，或选中后按 `Ctrl+D`；在置顶卡片下方用 `←` / `→` 调整顺序。右键卡片或点击“取消置顶”可以移除。

置顶顺序对应 `Alt+1` 到 `Alt+8`。如果某个工具被停用，它不会继续出现在启动器的可用工具中。

### 快捷键速查

| 快捷键 | 作用 | 生效位置 |
| --- | --- | --- |
| `Alt+Space` | 显示 / 隐藏 QuickBox | 全局，默认快捷键，可在设置中修改 |
| `↑` / `↓` | 选择上一个 / 下一个工具 | 启动器搜索和列表 |
| `Enter` | 打开选中的工具 | 启动器搜索和列表 |
| `Ctrl+D` | 置顶 / 取消置顶选中的工具 | 启动器，最多 8 个 |
| `Alt+1` … `Alt+8` | 打开对应位置的常用工具 | 启动器 |
| `Tab` / `Shift+Tab` | 向后 / 向前切换分类 | 焦点在搜索框中；工具已打开时，`Tab` 优先进入工具输入区 |
| `Ctrl+K` | 打开操作面板 | 启动器 |
| `Ctrl+1` | 切换到启动器 | 应用内 |
| `Ctrl+2` | 切换到插件管理 | 应用内 |
| `Ctrl+3` 或 `Ctrl+,` | 打开设置 | 应用内 |
| `Esc` | 逐层返回，最后隐藏窗口 | 启动器，具体行为见下文 |

在工具输入框编辑时，启动器的选择、置顶和数字快捷键不会接管正在输入的内容。`Esc` 会先关闭操作面板；在工具输入框中会先把焦点退回启动器搜索框，随后依次关闭工具、清空搜索，最后隐藏窗口。

全局快捷键发生冲突时，到 **设置 → 常规 → 启动器热键** 选择预设或填写组合键，然后点击 **保存热键**。主题、置顶窗口等开关会直接保存；托盘显示设置需要重启应用后生效。

## 3. 查 Linux 命令与用法

在启动器搜索 **Linux 命令大全**，或输入 `tar`、`grep`、`systemctl` 等命令名称，打开命令插件。

### 完整手册

内置 [jaywcjlove/linux-command](https://github.com/jaywcjlove/linux-command) 的 **621 份命令文档**，随应用打包，可以离线阅读。

1. 在插件内部的搜索框输入命令名、中文用途、选项或示例内容，例如 `压缩`、`网络`、`systemctl`。
2. 用分类选择器缩小范围，在左侧选择命令。
3. 右侧查看说明、语法、选项和实例；可复制单个代码块，也可点击 **复制完整手册**。
4. 结果较多时，点击列表底部的 **再显示** 继续浏览。

启动器搜索用于找到工具入口；**插件内部搜索会检索手册正文**。在插件搜索框中还可以用 `↑` / `↓` 切换命令，按 `Enter` 把焦点移到手册正文。

### tldr 示例

切换到 **tldr 示例** 页签，可以快速查看内置精简示例，并按平台筛选。示例中的 `{{name}}` 等占位符需要替换成实际参数。该页签保留的是独立的精简示例集，条目数量与完整手册不同。

命令插件负责查阅和复制用法，不会直接执行手册中的命令。完整手册采用 MIT 许可，具体来源、固定版本与许可证可在插件底部 **版本与许可证** 中查看；tldr 示例的来源与许可在对应页签说明中列出。

## 4. 保存个人命令、文件与代码片段

这几个入口适合不同的保存任务：

| 入口 | 适合保存 | 如何查找 | 文件大小限制 |
| --- | --- | --- | --- |
| **命令与文件** | 自己的命令、多行脚本，以及附带标签和备注的文件副本 | 标题、标签、命令内容、文件名与备注 | 文件最大 **20 MB / 个** |
| **本地代码片段** | 带语言标记的代码、模板和文本片段 | 标题、标签与内容 | 不接收附件 |
| **设置 → 统一备份管理** | ZIP、SQL、图片、文档等任意格式的备份文件 | 文件名 | 没有上述 20 MB 限制，受可用磁盘空间等条件约束 |

### 记录一条命令

搜索打开 **命令与文件**，点击 **新建命令**，填写标题、标签和命令内容，再点击 **保存命令**。之后可在此工具内检索并 **复制命令**。保存的命令不会自动执行。

### 保存文件副本

在 **命令与文件** 中点击 **保存文件**，可以一次选择多个文件。保存后可以编辑标题、标签和文件备注，也可以 **导出文件**。

文件以独立副本保存；之后移动、修改或删除原文件，不会同步改动已保存的副本。需要保留新版本时，再保存一份即可。删除资料时会同时删除该记录对应的已保存文件副本。

编辑内容后，请先 **保存** 或 **放弃修改**，再切换记录。代码片段也采用显式保存，不能把未保存的编辑当作已经备份的数据。

## 5. 统一保管备份文件

打开 **设置 → 统一备份管理**：

1. 点击 **添加备份文件**，通过系统文件选择器选择一个或多个文件。
2. QuickBox 把文件原样复制到当前数据目录的 `backups` 下，同名文件分别保留。
3. 用文件名搜索所需备份；点击 **导出** 可另存一份，点击 **打开备份文件夹** 可在文件管理器中查看。
4. 不再需要某份副本时点击 **删除**，再确认删除。

这里不解析备份内容，也不限定 JSON 格式。添加 SQL 文件不会导入数据库，添加 ZIP 不会自动解压；它也不会自动恢复 QuickBox 的设置或资料库。原文件后续变化不会自动同步，需要再次添加才能保存新副本。

导出备份时请选择**数据目录以外的位置**和**尚不存在的文件名**；Windows 下还需要选择非 C 盘目标。删除只移除 QuickBox 中这一份备份副本，不影响最初选择的原文件。

通过“添加备份文件”保存的内容才会形成可管理的备份条目。不要随意改动备份子目录结构；把文件直接丢进 `backups` 根目录，也不会自动出现在列表中。

## 6. 数据放在哪里，怎样迁移

默认情况下，数据目录与程序放在一起。以 Windows 安装路径 `D:\Apps\QuickBox` 为例：

```text
D:\Apps\QuickBox\
├── quickbox.exe
├── storage-location.json       # 迁移后创建，记录当前数据目录位置
└── data\                      # 默认数据目录
    ├── quickbox.sqlite3        # 配置、使用记录、个人资料索引等
    ├── saved-files\            # “命令与文件”中的文件副本
    ├── backups\                # “统一备份管理”中的文件副本
    │   └── <备份编号>\
    │       └── 原文件名.zip
    └── webview\                # 桌面界面的缓存与浏览器本地状态
```

部分子目录会在对应功能使用后创建。`webview` 是界面运行所需的缓存目录，不是安装另一份浏览器；命令记录和资料索引等主要数据保存在 SQLite 中。

### 换到另一个磁盘或文件夹

1. 打开 **设置 → 数据存储位置**，确认“当前目录”。
2. 点击 **选择文件夹**，通过系统文件夹选择器选择非 C 盘的**空文件夹**。
3. 点击 **迁移并使用**，保持应用开启，等待迁移完成提示。
4. 重启 QuickBox，让 WebView 缓存也切换到新位置。

迁移会复制数据库、`saved-files` 和 `backups`，原目录保留副本；成功后应用使用新目录。WebView 缓存不会随这次数据复制一起迁移，重启后会在新目录创建。新目录与当前数据目录不能互相包含，也不能覆盖已有文件。

安装目录中的 `storage-location.json` 保存的是新数据目录路径。只复制程序、拔掉数据盘，或手工移动新目录，都会使这个路径失效。请用设置中的迁移功能更改位置。

旧版升级时，应用会检查旧 AppData 数据并复制到新的安装目录；旧副本会保留。如果旧位置指向的磁盘不可用，请先接回原磁盘再启动。

### 备份完整的 QuickBox 数据

统一备份管理保存的是用户选择的文件。要给 QuickBox 本身做一次完整留档，请按以下步骤操作：

1. 保存所有正在编辑的内容，到设置中记录当前数据目录。
2. 从托盘菜单选择 **退出 QuickBox**，确保进程已退出。隐藏窗口或最小化不能代替退出。
3. 把**整个当前数据目录**复制到另一个备份位置，包含数据库、附件、备份和其他随目录保存的文件。
4. 如果迁移过数据目录，同时保留安装目录中的 `storage-location.json`，并记录它指向的路径。

需要回退数据时，先退出应用并保留现有目录副本，再把完整留档恢复到原数据路径。迁移过的安装需要让位置配置与实际目录一致；不要只恢复 SQLite 而遗漏文件副本。当前设置页没有一键恢复完整应用数据的入口。

## 7. 插件、剪贴板与联网范围

### 启停工具

按 `Ctrl+2` 打开 **插件管理**，按插件名或工具名搜索，再用“已启用 / 已停用”筛选。关闭一个插件，会一起隐藏它注册的工具入口；展开 **权限与详情** 可以查看声明的权限、命令数和视图数。

当前页面管理的是内置插件，并没有在线插件商店或安装任意第三方插件的入口。

### 分清两种剪贴板功能

| 功能 | 何时读取 | 是否持久化历史 |
| --- | --- | --- |
| **设置 → 工作台偏好 → 呼出时推荐剪贴板工具** | 开启后，在启动器获得焦点时识别文本，推荐对应工具；默认关闭 | 这个推荐功能本身不记录历史 |
| **剪贴板纯文本历史记录**工具 | 打开工具时默认开始监听，每 2 秒检查一次；可在工具内暂停，关闭或切换该工具后停止 | 保存到本地 SQLite，最多 **100 条**，重复文本刷新到最新位置 |

历史工具只保存纯文本，不保存图片和文件。可以搜索、复制、删除单条历史，或清空全部记录。暂停监听不会删除已经保存的历史；仅隐藏 QuickBox 窗口不会结束已打开工具的监听，再次打开该工具会默认开始监听。

### 哪些操作需要网络

内置格式化、编码转换、Linux 手册阅读和个人资料管理等核心功能在本地运行。**检查更新**会访问 GitHub API，打开官方发行页面、来源链接和外部资料也需要网络。手动检查更新用于查看最新正式版本，实际下载与安装通过发行页面完成。

## 8. 常见问题

| 情况 | 处理方法 |
| --- | --- |
| 启动提示不能保存到 C 盘 | 把程序安装到非 C 盘且可写的目录；确认该目录没有通过联接指向 C 盘 |
| 提示原数据目录不可用 | 接回数据盘、恢复原盘符或把完整数据恢复到原路径；不要删除位置配置来绕过提示，避免误用新空库 |
| 提示 `storage-location.json` 损坏 | 从备份恢复安装目录中的位置配置，确认其指向完整的数据目录 |
| 数据迁移提示目录非空或路径嵌套 | 选择与当前数据目录互不包含的空文件夹 |
| 升级时提示默认 `data` 目录已有文件 | 先备份并整理该目录，再重试旧版数据迁移；不要直接删除不明文件 |
| `Alt+Space` 没反应 | 通过托盘显示窗口，在设置中选择其他全局快捷键并保存，确认没有被其他软件占用 |
| 搜不到某个工具 | 检查启动器分类和搜索词，再到插件管理确认所属插件已启用 |
| “命令与文件”提示超过 20 MB | 需要保管大文件副本时使用设置中的“统一备份管理” |
| 备份导出提示文件已存在 | 更换导出文件名；应用不会覆盖目标文件 |
| 修改目录后仍看到旧 `webview` 文件夹 | 退出并重启应用后，新缓存位置才会生效；旧目录副本会保留 |
| 关闭推荐后仍有剪贴板历史 | 推荐与历史记录是两个功能；到历史工具中暂停监听，按需删除已有历史 |

需要报告问题时，请附上操作系统、QuickBox 版本、操作步骤和错误提示。发行与构建问题可同时参阅 [发布说明](release.md)，开发环境问题参阅 [开发指南](development.md)。
