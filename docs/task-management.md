# 任务管理

把待办、日程和重复事务放进 QuickBox，与工具、命令和个人资料一起使用。任务保存在当前本地数据目录，无需额外启动原 Task 程序。

[返回首页](../README.md) · [使用指南](usage.md) · [开发指南](development.md)

## 快速记下下一件事

1. 在启动器搜索 **任务管理**、`task`、`todo` 或“待办”，打开工具。
2. 在快速添加框输入 `明天下午三点开会`。
3. 检查下方预览：标题“开会”、日期“明天”、时间 `15:00`，再点击 **添加**。
4. 点击任务打开详情，按需补充描述、列表、优先级、提醒和子任务，点击 **保存任务**。

日期识别支持“今天 / 明天 / 后天”“周五 / 下周一”、`2026-10-20`、`10月20日`，时间支持 `15:30`、“下午三点”“九点半”等常用写法。仅输入时间时使用当天日期；没有写日期时，在“今天”视图创建的任务默认安排到今天。识别结果会显示在输入框下方，保存前可以核对；不认识或不合法的内容不会被当成有效日期。

自然日期用于快速添加。详情中的标题、截止日期和时间是独立字段，需要分别编辑；识别日期也不会自动开启提醒。

## 用视图安排工作

| 视图 | 包含的任务 |
| --- | --- |
| **今天** | 截止日期为今天或更早、尚未完成的任务，因此也包含逾期任务 |
| **收集箱** | 没有所属列表、尚未完成的任务，不以是否设置日期为准 |
| **未来 30 天** | 截止日期从明天起、至今天后第 30 天的未完成任务 |
| **全部未完** | 所有未完成且未删除的任务，包括没有日期的任务 |
| **已完成** | 已标记完成、未删除的任务，可以撤销完成 |
| **回收站** | 已删除的任务，可以恢复或手动永久删除 |
| **列表 / 标签** | 关联到所选列表或标签、尚未完成的任务 |

顶部统计显示今天待办、逾期和今天完成的数量。在任务内搜索标题、描述、列表名或标签名时，会跨视图搜索未删除任务，**包括已完成任务，不包括回收站**。清空搜索词后返回所选视图。结果较多时，可点击 **加载更多任务**。

## 整理任务详情

- **列表**：用工作、生活或项目划分任务；在“管理列表和标签”中创建，再到详情选择所属列表。每个任务最多属于一个列表。
- **标签**：可为同一任务勾选多个标签，按标签筛选。
- **优先级与置顶**：P1 最高，P4 为默认。任务先按置顶和优先级排序；列表中的上移、下移按钮可调整顺序，跨优先级移动时，被移动任务会采用相邻任务的优先级。
- **子任务**：拆成具体步骤并单独勾选完成；主任务与子任务的完成状态分别保存。

修改详情后需要点击 **保存任务**。有未保存修改时，先保存或放弃修改再切换；创建空白子任务后，请填写标题或移除该项后再保存。

删除列表只把关联任务移回收集箱，删除标签只移除任务上的该标签，均保留任务本身。删除任务会移入回收站；永久删除需要再次确认，之后无法从任务工具中恢复。

### 最近创建模板与复制任务

快速创建或保存任务后，“最近创建模板”最多保留 **12 条**可复用模板。点击模板会打开新任务草稿，确认内容后保存；已有任务详情中的 **复制任务** 也会生成新草稿。

复用时任务为未完成、未置顶，子任务重置为未完成，并分配新标识；早于今天的截止日期及其时间、提醒和重复设置会清空，避免直接沿用旧日程。模板保存在 QuickBox 的本地设置中，不属于任务 JSON 导出内容。

## 重复任务与到期提醒

### 完成一次，生成下一次

设置截止日期后，可以选择 **每天、工作日、每周、每月或每年**重复。标记完成时，会依据该任务的截止日期生成下一期未完成任务，沿用标题、描述、列表、标签、优先级、提醒及子任务，子任务的完成状态重置。

工作日规则跳过周六和周日，不读取法定节假日安排。月末和闰日按目标月份最后一天处理，例如 `2024-01-31` 每月重复的下一期为 `2024-02-29`，`2024-02-29` 每年重复的下一期为 `2025-02-28`。下一期从原截止日期推进，不以点击完成的当天重新计算。

撤销完成后再完成，同一截止日期和重复规则不会再生成一份相同下一期；已经生成的下一期也不会因撤销上期而自动删除。

### 让提醒按时出现

1. 在详情设置 **截止日期** 和 **截止时间**。
2. 选择 **到期时**，或提前 5 / 10 / 15 / 30 / 60 分钟、1 天提醒。
3. 保存任务，并保持 QuickBox 运行。

桌面程序每 **15 秒**检查一次到达提醒时刻的未完成任务；主窗口隐藏、应用留在托盘时仍会检查。提醒弹窗可选择 **查看任务** 或 **知道了**。同一计划确认后不再重复提醒，调整日期、时间或提醒提前量会重新安排提醒。

提醒按本机日期与时间计算，受后台检查间隔影响；**退出 QuickBox 后不会提醒**。关闭“任务管理”插件也会停止提醒。浏览器开发预览不提供原生桌面后台提醒。

## 从原 Task 迁移

推荐使用 **JSON** 保留主要任务字段：

1. 在原 Task 打开 **设置 → 导出任务 → JSON**，保留导出的文件。
2. 在 QuickBox 打开 **任务管理**，点击工具栏上的 **导入和导出** 图标。
3. 点击 **选择导入文件**，选择刚才的 JSON 文件。
4. 查看新增、跳过数量及错误提示，再核对“全部未完”“已完成”、列表和标签中的数据。

JSON 导入保留标题、描述、完成状态、优先级、列表、标签、子任务及其完成状态、截止日期和时间、提醒、重复规则与置顶状态。缺少的列表、标签按名称创建，已有同名项复用。

导入会**重新分配任务和子任务 ID**，不会按原 ID 覆盖或去重；再次导入同一个文件会再次创建任务。原创建 / 更新时间、完成时刻、排序、提醒确认记录和重复生成记录不作为迁移身份保留。原 Task 的回收站不在导出范围内，也不会自动把原 Task 设置、窗口布局或数据目录配置搬进 QuickBox。

### 三种格式如何选择

| 格式 | 适合用途 | 导出的主要内容 |
| --- | --- | --- |
| **JSON** | 从 Task 迁移、保留主要任务字段 | 标题、描述、状态、优先级、列表、日期、时间、标签、子任务、重复、提醒和置顶等 |
| **CSV** | 表格查看、交换有限字段 | 标题、描述、状态、优先级、列表、日期、时间、标签和创建时间；不包含子任务、重复、提醒和置顶 |
| **Markdown** | 阅读或简单勾选清单 | 标题、完成状态、截止日期和单行描述；不包含列表、标签、子任务、优先级、重复和提醒 |

三种导出格式均导出**全部未删除任务，包括已完成任务**，不受当前视图或搜索词限制，不导出回收站。CSV 导入可识别对应中英文表头；Markdown 导入识别 `- [ ]` / `- [x]` 清单，日期形式为标题后的 `(YYYY-MM-DD)`，描述使用 ` — ` 分隔。需要迁移完整任务字段时请使用 JSON。

### 导入限制与错误处理

单文件最大 **8 MB**，单次最多 **10000 项**。JSON 支持任务数组，以及包含 `tasks` 数组的对象；文件扩展名支持 `.json`、`.csv`、`.md` 和 `.markdown`。

文件格式、字段类型或日期格式错误会在解析阶段停止导入，提示出错位置，本次不会写入任务。通过解析后，后端继续逐条校验标题、长度、日期与提醒依赖等业务条件；非法项跳过，并显示新增、跳过数量和部分错误原因。每条任务的写入使用独立保存点，该条失败时，刚为它创建的列表、标签也一并回滚。

导入结果含跳过项时，先按提示修复文件并确认已成功导入的部分。重新导入整份文件仍会再次创建其中成功过的任务。

## 数据与备份

任务、列表、标签、子任务、重复生成记录及提醒状态保存到 QuickBox 当前数据目录下的 `quickbox.sqlite3`；最近模板保存在同一数据库的任务设置命名空间。更改 **设置 → 数据存储位置** 时，这些内容跟随统一数据库迁移，无需为任务单独设置目录。

任务 JSON 是可交换的任务数据副本，不能替代整个应用的备份；工作台偏好备份也不包含任务。完整留档请先**退出 QuickBox**，再复制整个当前数据目录，并保留安装目录中的 `storage-location.json`（若存在）。详细操作见 [完整数据备份](usage.md#data-management)。

## 来源与合并范围

本模块基于 [CrescentR/Task](https://github.com/CrescentR/Task) 固定提交 [`da88479b63686694a4048343550623dd7669b11a`](https://github.com/CrescentR/Task/tree/da88479b63686694a4048343550623dd7669b11a) 的基础任务能力移植并适配。该来源快照未附 `LICENSE` 文件，此处不将其标注为 MIT 或其他开源许可证。

任务功能以 QuickBox 内置插件提供，复用宿主窗口、主题、全局呼出方式与数据目录。原 Task 的 mini / 便签模式、独立窗口快捷键和独立数据位置策略未移入；原 SQLite 文件也不会直接覆盖 QuickBox 数据库，已有数据通过导入功能合并。

开发入口和存储规范见 [开发指南 → 任务管理模块](development.md#任务管理模块)。
