# QuickBox 架构说明

QuickBox 是一个基于 Tauri 2、React、TypeScript、Rust 和 SQLite 的轻量级桌面启动器。

## 架构原则

前端负责体验层。  
Rust 负责系统能力层。  
插件是能力消费者，不能直接访问敏感系统 API。

## 前端职责

- 启动器 UI
- 命令输入
- 命令列表渲染
- 工具视图
- 设置页
- 插件管理界面
- 轻量内置工具逻辑

## Rust Core 职责

- 全局快捷键
- 窗口显示与隐藏
- 窗口聚焦
- 系统托盘
- 剪贴板访问
- SQLite 存储
- 本地应用配置
- 插件权限校验
- 平台差异行为

## 插件规则

- 所有工具都必须注册为插件。
- 内置工具同样是插件。
- `LauncherPage` 不能直接导入具体工具。
- 命令必须从 `PluginRegistry` 发现。
- 敏感 API 必须通过 Rust command 访问。
- 插件必须声明权限。
- 权限检查由 Rust 执行。

## V0.1 范围

- 仅加载内置插件
- 不执行外部插件
- 不提供插件市场
- 不引入用户账户
- 不支持同步
- 不接入云服务
