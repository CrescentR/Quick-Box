Plain text
实现命令系统。

实现内置插件系统。

实现 PluginRegistry。

实现官方内置插件：
1. official.json-tool
2. official.timestamp-tool
3. official.base64-tool
4. official.uuid-tool
 Phase 4
每个插件必须提供 index.ts。
每个插件至少注册一个 command。
需要 UI 的插件必须注册 view。
实现 PluginRegistry 和 BuiltinPluginLoader。
把 JSON、时间戳、Base64、UUID 四个工具作为 builtin plugin 注册。
插件视图使用 React ComponentType。
不要生成任何 Vue 文件。
Phase 5
实现插件 view 动态渲染。
每个工具拥有自己的 React 组件页面。
Command 通过 ctx.openView 打开对应 view。
LauncherPage.tsx 通过 PluginRegistry.getView(viewId) 获取组件并动态渲染。
禁止使用 if/else 或 switch 判断具体插件类型。
